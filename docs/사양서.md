## 개요

길터줘는 긴급차량이 다가오면 Pleos 차량 화면과 음성으로 알리고, 차량 상태에 맞는 양보 행동을 안내하는 앱이다. 공모전 MVP는 송신·서버·수신 3개 구성으로 처음부터 끝까지 실제로 동작하는 시스템을 만든다.

- **데이터 출처 우선순위**: 1순위 공공 GPS(경찰청·소방청 연계), 2순위 송신용 GPS.
- **공공 GPS**: 공개 허가를 받지 못해 공모전 기간에는 서버에 연동 자리만 만든다. 그동안은 송신용 GPS로 임시 구현한다.
- **송신 수단**: 긴급차량에 Pleos가 탑재돼 있으면 차량 앱의 송신 모드, 탑재돼 있지 않으면 스마트폰 앱(안드로이드)으로 송신한다. 차량용과 폰용은 같은 길터줘 앱이고 설치 파일만 2개다.
- **위치 공유**: 긴급출동 모드가 켜져 있을 때만 위치를 보낸다. 상시 공유하면 긴급차량의 위치가 추적되기 때문이다.
- **차별점 (양방향)**: 일반 차량이 양보하면 차가 방향지시등·감속·정차로 자동 감지해 긴급차량에 알린다 (길 열림 확인). 카카오내비·경찰청 안내 서비스 같은 기존 서비스는 긴급차량에서 일반 차량으로 가는 한 방향 알림이다.
- **범위 밖**: 사이렌 소리 감지(제외 결정). 앰비언트 라이트는 공모전용 SDK 제공이 확인돼 R-15로 포함한다(에뮬레이터 시험 필요).

## 시스템 구성

```
[송신]                          [서버: Supabase]                       [수신: Pleos 차량 앱]
공공 GPS (협약 후 1순위) --->   공공 GPS 어댑터 (협약 전 꺼둠)
Pleos 송신 모드 ----------->    긴급차량 현재 위치 positions_live  --실시간 구독-->  내 차 위치 / 거리·방향·도착 시간
스마트폰 앱 송신 ---------->      (차량당 1행, 10초 만료)                              차량 상태 읽기 / 알림·양보 안내
        <--- 길 열림 현황 (S-8) ---  yield_acks (익명 양보 확인)  <--양보 확인(R-16)--
```
송신은 긴급출동 모드일 때만 한다. 수신 차량은 알림 중에만 익명 양보 확인을 보내고, 긴급차량은 이를 길 열림 현황으로 본다.

공공 GPS가 연계되면 서버의 어댑터만 켜면 되고, 수신 앱은 바꿀 필요가 없다. 같은 차량이 공공과 송신 양쪽에 있으면 공공 데이터를 쓴다.

## 송신 기능

송신 기능은 긴급출동 모드가 켜진 긴급차량의 위치를 1초마다 서버로 보낸다. 모드가 꺼져 있으면 아무것도 보내지 않는다. 상시 공유하면 긴급차량의 위치가 추적되고, 도로교통법상 긴급자동차도 긴급한 용도로 운행 중일 때만 해당하기 때문이다.

| ID | 기능 | 사양 | 스마트폰 앱 | Pleos 송신 모드 |
| --- | --- | --- | --- | --- |
| S-1 | 차량 등록 | 등록 코드를 입력하면 차량 ID와 차종(구급차·소방차·경찰차)을 확인한다. 미등록 코드는 송신 불가 | 있음 | 있음 (설정 화면) |
| S-2 | 긴급출동 모드 | 큰 버튼 하나로 켜고 끈다. 켜져 있을 때만 송신하고 시작·종료 시각을 기록한다. 데모는 수동 버튼이고, Pleos 탑재 긴급차량은 사이렌·경광등 스위치와 연동해 자동으로 켜고 끈다(확장) | 있음 (수동) | 있음 (데모는 수동, 실차는 자동 연동) |
| S-3 | 위치 송신 | 1초 주기. 위도, 경도, 진행 방향, 속도, 정확도, 시각 | 안드로이드 위치 기능 (폰 GPS) | FusedLocation SDK (안 되면 안드로이드 표준 위치 기능) |
| S-4 | 시연용 경로 재생 | 미리 정한 경로를 실제 속도로 재생해 송신하고, 화면에 “시연 모드”를 표시한다 | 있음 | 있음 |
| S-5 | 백그라운드 송신 | 화면이 꺼지거나 다른 앱을 써도 계속 송신한다. 송신 중에는 알림창에 ‘긴급출동 송신 중’을 표시한다 (안드로이드 규칙) | 있음 | 있음 |
| S-6 | 송신 상태 표시 | 마지막 송신 시각을 보여주고, 5초 넘게 실패하면 경고한다 | 있음 | 있음 |
| S-7 | 출동 확인 | 긴급출동 모드가 60분 넘게 켜져 있으면 알림음과 함께 “아직 출동 중인가요?”를 묻는다. “출동 중” 버튼 하나를 누르면 60분 연장하고, 2분 안에 응답이 없으면 자동으로 끄고 ‘자동 종료’로 기록한다. 시간은 제안값 | 있음 | 있음 |
| S-8 | 길 열림 현황 | 긴급출동 중 화면에 앞쪽(진행 방향 500m)에서 알림을 받은 차와 양보한 차 수를 실시간으로 표시한다. 예: ‘알림 7대 · 양보 5대’ | 있음 | 있음 |

긴급출동 중 화면은 송신 상태와 끄기 버튼만 두어 운전 중 조작을 없앤다. 폰용 송신 앱은 공공 GPS 연계 전까지의 임시 수단이고, 위치 권한을 ‘항상 허용’으로 받아야 한다.

## 서버

서버는 Supabase로 만들고, 출처가 달라도 같은 형식의 긴급차량 위치를 수신 앱에 실시간으로 전달한다.

| 테이블 | 용도 | 주요 항목 |
| --- | --- | --- |
| vehicles | 등록 차량 | 차량 ID, 등록 코드, 차종, 운용 기관, 사용 여부 |
| dispatches | 출동 기록 | 출동 ID, 차량 ID, 시작·종료 시각, 종료 방식(수동·자동), 출처 |
| positions\_live | 현재 위치 (차량당 1행) | 차량 ID, 위도, 경도, 진행 방향, 속도, 정확도, 갱신 시각, 출처 |
| yield\_acks | 양보 확인 (익명) | 출동 ID, 대략 위치, 상태(알림 받음·양보함), 시각. 차량 ID 없음, 출동이 끝나면 삭제 |

- **실시간 전달**: positions\_live가 바뀌면 수신 앱에 바로 보낸다 (Supabase 실시간 구독).
- **만료**: 10초 넘게 갱신이 없는 차량은 활성 목록에서 뺀다.
- **긴급출동 종료**: 모드가 꺼지면 positions\_live에서 그 차량을 바로 지운다. 이동 경로는 저장하지 않고, dispatches에는 시작·종료 시각만 남긴다.
- **출처 구분**: 출처는 public(공공 GPS) 또는 sender(송신용 GPS). 같은 차량이 둘 다 있으면 public을 쓴다.
- **공공 GPS 어댑터**: 공공 데이터를 같은 형식으로 바꿔 positions\_live에 넣는 자리다. 협약 전에는 꺼두고, 시연에서는 시연 데이터로 흐름만 보여줄 수 있다.
- **보안**: 쓰기는 등록 코드가 맞는 송신자만, 수신 앱은 읽기와 yield\_acks 쓰기만 허용한다 (Supabase 테이블 접근 규칙).
- **개인정보**: 수신 차량은 평소에 위치를 서버로 보내지 않는다. 활성 긴급차량 목록만 받아 차 안에서 계산한다. 알림이 떠 있는 동안에만 익명 양보 확인과 대략 위치를 보내고, 출동이 끝나면 지운다.

| R-17 | 양보 리포트 | 양보가 확인되면 ‘오늘 구급차 1대에 길을 열어줬습니다’를 보여주고 누적 횟수를 남긴다. 기록은 차 안에만 저장한다 | 앱 내부 저장 | 가능 |

## 알림 단계와 양보 안내

알림은 거리와 도착 예상 시간에 따라 3단계로 올라가고, 양보 단계에서는 차량 상태에 맞는 행동 하나만 안내한다. 기준값은 제안값이며 시연 후 조정한다.

| 단계 | 조건 (먼저 충족되는 쪽) | 화면 | 소리 |
| --- | --- | --- | --- |
| 관심 | 1,000 m 이내 + 접근 중 | 상단 알림 카드 (다른 앱 위), 앰비언트 주황 | 알림음 1회 |
| 경고 | 500 m 이내 또는 도착 30초 이내 | 접근 알림 화면: 거리·방향·도착 시간, 가장자리 붉은 빛, 앰비언트 라이트 붉은색 | 알림음(오는 쪽 스피커) + 음성, 음악 볼륨 낮춤 |
| 양보 | 200 m 이내 또는 도착 15초 이내 | 양보 안내 화면: 큰 아이콘 1개 + 한 줄 문구, 앰비언트 붉은색 깜빡임 | 음성 안내 |
| 해제 | 멀어지는 중, 또는 데이터 끊긴 뒤 5초 | 해제 화면 3초 후 원래 화면 | 완료음, 음악 볼륨·앰비언트 라이트 복원 |

양보 문구는 도로교통법 제29조를 따른다. 교차로 부근에서는 교차로를 피해 일시정지하고, 그 밖의 곳에서는 진로를 양보한다 (조문 원문은 기획서 작성 전에 다시 확인).

| 상황 | 판단 조건 | 안내 문구 |
| --- | --- | --- |
| 주행 중, 후방 접근 | 속도 5 km/h 초과 + 상대 방향 후방 | “우측으로 비켜주세요” |
| 주행 중, 전방·측면 접근 | 속도 5 km/h 초과 + 상대 방향 전방·좌측·우측 | “속도를 줄이고 진로를 비켜주세요” |
| 정차 중, 측면에서 교차 접근 | 속도 0 + 브레이크 밟음 + 긴급차량 진행 방향이 내 진행 방향과 교차 | “녹색 신호여도 교차로에 진입하지 마세요” |
| 양보 행동 확인 | 우측 방향지시등 켜짐 | “확인했습니다” 표시, 반복 안내 멈춤 |
| 통과 후 | 거리가 늘어남 | “지나갔습니다”, 정차 중이었으면 “출발하셔도 됩니다” |

주행 중에는 아이콘 하나와 문구 한 줄만 보여준다. 대기 화면에는 “알림이 없어도 사이렌에 주의하세요”를 항상 표시한다. 모든 긴급차량이 송신하는 것은 아니기 때문이다.

주행 중에는 앱 화면이 막힐 수 있다(설명회에서 답변 보류). 그래서 양보 안내는 음성과 앰비언트 라이트로 먼저 전달하고, 화면은 보조로 쓴다. 화면이 막혀도 시연 시나리오가 성립해야 한다.

## 화면 목록

수신 앱 7개, 송신 4개 화면으로 구성한다. 수신 화면 시안은 [3D 시연 페이지](https://claude.ai/artifact/1y4R1RiKQWpKGpTZbESEDL)의 차량 화면을 출발점으로 삼는다.

| 구분 | 화면 | 내용 |
| --- | --- | --- |
| 수신 | 대기 | 서버 연결 상태, 주변 긴급차량 수, “알림이 없어도 사이렌에 주의하세요” |
| 수신 | 상단 알림 카드 | 차종, 방향, 거리. 다른 앱 위에 뜨며 누르면 접근 알림 화면 |
| 수신 | 접근 알림 | 내 차 기준 레이더, 거리, 방향, 도착 예상 시간 |
| 수신 | 양보 안내 | 큰 아이콘 1개, 한 줄 문구, 행동 확인 표시 |
| 수신 | 해제 | 통과 안내, 3초 뒤 원래 화면으로 |
| 수신 | 설정 | 수신·송신 모드 전환, 등록 코드 입력, 알림 거리 |
| 수신 | 양보 리포트 | 길을 열어준 기록과 누적 횟수 (R-17) |
| 송신 | 등록 | 등록 코드 입력 |
| 송신 | 대기 | 차량 정보, 긴급출동 모드 버튼 |
| 송신 | 긴급출동 중 | 송신 상태, 마지막 송신 시각, 긴급출동 끄기 버튼, 출동 확인 질문(S-7), 길 열림 현황(S-8) |
| 송신 | 시연 모드 | 경로 선택(후방 접근, 교차로 측면 접근), 재생·정지 |

Pleos 송신 모드는 수신 앱 설정에서 등록 코드를 넣으면 켜지고, 송신 화면 3개(대기·긴급출동 중·시연 모드)를 폰 앱과 같은 구성으로 쓴다.

## 공모전 시연 시나리오

PT에서는 송신(폰 앱이나 차량 앱의 시연 모드), 서버, 수신(에뮬레이터)을 모두 실제로 돌리고, 차량 상태는 Virtual Console로 바꾼다. 긴급차량의 이동 경로만 시연용이고, 송신에서 수신까지의 통신은 실제로 동작한다. 실제 GPS 시연은 도로에서 미리 찍은 영상(폰 앱 송신 → 에뮬레이터 수신)으로 보여준다. 심사위원은 차량 앱의 시연 모드로 폰 없이 시험할 수 있다.

| 순서 | 장면 | 조작 | 보여주는 기능 |
| --- | --- | --- | --- |
| 1 | 평소 주행 | 에뮬레이터 위치를 경로대로 이동, 내비 사용 중 | R-1, R-5, R-9 |
| 2 | 구급차 출동 | 긴급출동 모드를 켜고 시연 모드에서 ‘후방 접근’ 재생 | S-2, S-4, R-2 |
| 3 | 첫 알림 (관심) | 1,000 m 진입 시 자동 | R-3, R-4, R-11 |
| 4 | 접근 경고 | 500 m 진입 시 자동 | R-10, R-12, R-13, R-15 |
| 5 | 양보 안내 | 200 m 진입 시 자동: “우측으로 비켜주세요” | R-5, R-9 |
| 6 | 양보 확인 | Virtual Console에서 우측 방향지시등 켬 → 폰 송신 앱에 ‘양보 1대’ 표시 | R-7, R-16, S-8 |
| 7 | 통과·해제 | 구급차 통과 후 자동 | R-13·R-15 복원, R-17 기록 |
| 8 | 교차로 정차 | Virtual Console에서 브레이크 100%, 에뮬레이터 위치 정지 | R-6 |
| 9 | 소방차 측면 접근 | 시연 모드에서 ‘교차로 측면 접근’ 재생: “녹색 신호여도 교차로에 진입하지 마세요” | R-3, R-4, R-6 |
| 10 | 출발 안내 | 소방차 통과 후 자동: “출발하셔도 됩니다” | R-14 |
| 11 | 긴급출동 종료 | 긴급출동 모드 끄기: 서버에서 위치가 바로 지워지고 수신 목록에서 사라짐 | S-2, R-2 |

에뮬레이터에서 속도를 바꾸는 방법은 아직 확인하지 못했다. Virtual Console에는 현재 속도 항목이 없어서, 추가 설정을 찾지 못하면 위치 변화로 속도를 계산한다. 에뮬레이터 위치를 바꿀 수 없으면 수신 앱의 ‘시연용 내 차 경로’로 대신하고 화면에 “시연 모드”를 표시한다.

## 확장 로드맵

공모전 이후 확장은 외부 조건이 풀리는 순서대로 적용한다. 어느 항목이든 수신 앱의 구조는 바꾸지 않는다.

| 항목 | 지금 | 풀리는 조건 | 적용 내용 |
| --- | --- | --- | --- |
| 공공 GPS 연계 | 서버에 연동 자리만 구현 | 경찰청 도시교통정보센터·소방청과 협약 (카카오모빌리티와 같은 방식) | 공공 데이터를 1순위 출처로 사용 |
| 앰비언트 라이트 | 공모전 MVP에 포함 (R-15). 에뮬레이터 시험 필요 | 실차 배포 시 Light 제어 권한 승인 (App Market 심사) | 긴급차량이 다가오는 쪽 실내등의 밝기와 색상 변경 |
| 음성 안내·응답 | TTS SDK (ON\_DEVICE) | STT SDK 에뮬레이터 시험 | “알았어” 같은 음성 응답 |
| 경로 겹침 판단 | 상대 방향과 진행 방향으로 판단 | NaviHelper 경로 정보 확인 | 내 경로 위 긴급차량만 경고, 교차로 판단 정확도 향상 |
| 민간 구급차 | 스마트폰 앱 송신 | 구급차기록관리시스템(AiR) 연동 검토 | 민간 구급차 위치 자동 수신 |
| 긴급출동 자동 전환 | 수동 버튼 (데모) | Pleos 탑재 긴급차량의 사이렌·경광등 스위치 신호를 읽는 방법 확인 (차량 개조 사양에 따라 다름) | 사이렌·경광등을 켜면 긴급출동 모드가 자동으로 켜지고, 끄면 꺼진다 |
| 아이폰 송신 | 안드로이드 폰만 | iOS 앱 개발 | 아이폰을 쓰는 기관·차량도 송신 |
| 협력형 길 만들기 | 모든 차에 같은 방식으로 안내 | 차로 정보 SDK 공개 (10/31 기준 ADAS 문서는 비공개, NaviHelper에는 차로 정보 없음) | 차로별로 다른 역할 안내 (예: 1차로는 왼쪽, 나머지는 오른쪽. 소방청 길터주기 요령 확인 후) |
| 양보 보상 연계 | 양보 리포트 (차 안 기록) | 안전운전 프로그램·보험 제휴 | 양보 실적에 보상 |
