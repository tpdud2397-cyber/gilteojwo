# 길터줘 코드 설명 노트

2차 PT 기술 Q&A 대비용. 모듈별로 "무엇을, 왜" 했는지 적는다. 코드가 바뀌면 같이 고친다.

## 전체 구조

- 한 프로젝트에서 설치 파일(APK) 두 개를 만든다. 이 설정을 product flavor라고 한다.
  - `phone` (폰용, 송신): 지금은 "준비 중" 화면 하나. Pleos SDK를 넣지 않는다.
  - `car` (차량용, 수신 + Pleos 송신 모드): 지금은 시험 화면. Pleos SDK를 넣는다.
- 폴더
  - `app/src/main`: 두 앱이 함께 쓰는 것 (앱 이름, 아이콘, 빌드 정보)
  - `app/src/phone`: 폰용만
  - `app/src/car`: 차량용만 (권한 선언, 시험 화면)
- 앱 ID가 `com.gilteojwo.phone`, `com.gilteojwo.car`로 달라서 한 기기에 둘 다 설치할 수 있다.

## 빌드와 배포

- main에 올리면 GitHub Actions(`.github/workflows/build.yml`)가 두 APK를 만들어 Releases의 "개발 최신판"을 새 파일로 바꾼다.
- 화면에 빌드 번호와 커밋 번호를 보여줘서, 최신 APK가 깔렸는지 바로 알 수 있다.
- 개발용 서명 키(`app/debug.keystore`)를 저장소에 넣었다. 매번 같은 도장이 찍혀서 지우지 않고 덮어 설치할 수 있다. 시험판 전용이고 비밀이 아니다. 제출용 정식판은 별도 키를 GitHub Secrets에 둔다.
- Pleos SDK는 Pleos Maven 저장소에서 받는다. 위치 SDK는 저장소에 1.1.3만 있어서 1.1.3을 쓴다 (문서에는 1.1.2로 적혀 있음).

## 시험 화면 (`app/src/car/.../sdktest`)

사양을 확정하기 전에 Pleos 에뮬레이터에서 무엇이 되는지 확인하는 임시 화면이다. 본 개발이 시작되면 다섯 모듈(내 위치 / 긴급차량 수신 / 접근 판정 / 알림 / 송신)로 새로 만든다.

| 파일 | 하는 일 | 왜 |
| --- | --- | --- |
| `SdkTestActivity` | 화면을 왼쪽·오른쪽 칸으로 나누고, 시험 항목 7개를 만든 뒤 권한을 받고 시작한다. 시작하다 오류가 난 항목은 맨 위 줄에 표시하고 나머지는 계속 시험한다 | 한 화면에서 Virtual Console을 바꿔 가며 바로 보기 위해. 한 항목의 오류로 앱 전체가 꺼지지 않게 |
| `TestCard` | 시험 칸 하나 (제목, 결과 글자, 버튼 줄). 결과는 로그(`Gilteojwo`)에도 남긴다. 버튼에서 오류가 나면 그 칸에 글자로 보여준다 | 항목마다 같은 모양으로 단순하게 |
| `PermissionHelper` | 선언한 권한 중 아직 없는 것을 요청하고, 상태를 맨 위에 보여준다 | 위치·속도 권한은 'dangerous' 등급이라 실행 중 허락이 필요 |
| `LocationTest` ① | Pleos FusedLocation과 안드로이드 기본 위치를 나란히 받는다 | 에뮬레이터 위치 변경을 어느 쪽이 따라가는지 확인 (R-1) |
| `DrivingLimitTest` ② | 주행 제한 상태, 우리 화면의 주행용 인정 여부, 화면이 가려진 횟수 | 주행 중 화면이 막히는지 확인 (R-9·R-10) |
| `AmbientLightTest` ③ | 앰비언트 지원 범위 조회, 켜기·끄기·색·밝기 바꾸기, 원래대로 | 구역별 제어와 빨강 가능 여부 확인 (R-15) |
| `SpeechTest` ④ | 같은 문장을 Pleos TTS(ON_DEVICE)와 안드로이드 TTS로 읽는다 | 한국어 음성 품질과 동작 확인 (R-12) |
| `StereoBeepTest` ⑤ | 코드로 만든 "삐" 소리를 왼쪽·오른쪽 한쪽에서만 낸다 | 오는 쪽 스피커 알림음이 되는지 확인 (R-12) |
| `AlertOverNaviTest` ⑥ | 10초 뒤 상단 알림, 10초 뒤 화면 위 빨간 띠 | 내비를 쓰는 중에도 알림이 보이는지 확인 (R-11) |
| `VehicleStateTest` ⑦ | 속도·기어(안드로이드 표준), 브레이크·방향지시등(Pleos)을 실시간으로 받는다 | 양보 안내와 양보 감지에 쓸 값이 들어오는지 확인 (R-5~R-8) |

### 어떤 값을 어디서 읽는가 (Pleos 문서 기준)

- 속도: 안드로이드 표준 `PERF_VEHICLE_SPEED`. Pleos FAQ에 "계기판이 이 값을 쓴다"고 되어 있다.
- 기어: 안드로이드 표준 `GEAR_SELECTION`. Pleos Vehicle SDK의 기어 API는 "표준 GEAR_SELECTION을 쓰라"며 폐지 예정이다.
- 브레이크 페달, 방향지시등, 앰비언트 라이트: Pleos Vehicle SDK (`Brake`, `TurnSignal`, `Light`).
- 위치: Pleos FusedLocation SDK. 진행 방향은 있지만 속도는 없다.
- 음성: Pleos TextToSpeech SDK, ON_DEVICE 모드 (앱 등록 불필요).

### 권한

- Pleos Vehicle 권한(`CAR_DRIVE`, `CAR_LIGHTS`)은 'normal' 등급이라 선언만 하면 된다. 앰비언트 라이트 바꾸기도 `CAR_LIGHTS`로 된다.
- Pleos 위치(`FUSED_LOCATION`)와 안드로이드 속도(`CAR_SPEED`)는 'dangerous' 등급이라 실행 중에 허락을 받는다.
- '다른 앱 위에 표시'는 설정 화면에서 따로 허용한다.

### SDK 사용 순서 (공통)

1. 만들기: `Vehicle(context)`, `FusedLocation(context)`, `TextToSpeech(context, Mode.ON_DEVICE)`
2. 시작: `initialize()`
3. 값 받기: `registerXxx(listener)` 또는 `getXxx(onComplete, onFailed)`. 결과는 다른 스레드에서 올 수 있어서 화면 글자는 메인 스레드에서 바꾼다.
4. 끝: `unregisterXxx(listener)` → `release()`
