# 길터줘

**긴급차량이 다가오면 Pleos 차량이 화면·음성·실내 조명으로 알리고, 지금 차 상태에 맞는 양보 행동 하나를 안내하는 차량용 앱입니다.**
일반 차량이 양보하면 차가 스스로 감지해 긴급차량에 "길 열림"을 알려 줍니다(양방향).

현대자동차그룹 차량용 앱 개발 공모전(Pleos Connect) 출품작 · 시연 영상: https://youtu.be/_DqJL4MAPiA

## 무엇을 하나요

- **접근 알림 3단계**: 관심(1,000m) → 경고(500m 또는 30초) → 양보(200m 또는 15초) → 해제. 거리·8방향·도착 예상 시간을 계산합니다.
- **내비를 보는 중에도 알림**: 앱을 열지 않아도 뒤에서 도는 수신 서비스가 내비 위에 상단 카드를 띄우고, 긴급차량이 오는 쪽 화면 가장자리를 붉게 밝힙니다.
- **소리와 조명**: 오는 쪽 스피커에서 알림음, "뒤에서 구급차, 약 500미터" 같은 음성 안내, 실내 앰비언트 조명(관심 주황 → 경고 빨강 → 양보 빨강 깜빡임), 알림 동안 음악 소리 줄이기.
- **차 상태에 맞는 양보 안내**: 속도·브레이크·방향지시등·기어를 읽어 "우측으로 비켜주세요", "녹색 신호여도 교차로에 진입하지 마세요" 같은 행동 하나만 안내합니다. 주행 중에는 그림 하나와 문구 한 줄로 화면을 단순하게 바꿉니다.
- **양보 자동 감지 (길 열림 확인)**: 알림 중 우측 방향지시등·감속·정차를 보고 양보를 판단해 차량 ID 없이 서버에 알립니다. 긴급차량 화면에는 "알림 N대 · 양보 N대"가 보이고, 내 차에는 양보 리포트가 남습니다.
- **송신**: 긴급차량은 폰 앱 또는 차량 앱의 송신 모드로 긴급출동 중에만 1초마다 위치를 보냅니다. 심사·시연용으로 미리 정한 경로를 실제 속도로 재생하는 **시연 모드**가 있습니다.

## 시험 환경

- Pleos Connect Emulator **v2.1.0** (AVD `Pleos_Connect_v2.1`, Android 14 / API 34, x86_64)
- Pleos Connect **Virtual Console** (기어·브레이크·방향지시등·앰비언트 조명을 바꿀 때 사용)
- **인터넷 연결** (긴급차량 위치를 주고받는 서버: Supabase)
- 폰 앱을 쓸 경우 Android 9 이상 폰

## 실행 방법: 차량 앱 한 대로 시연하기 (폰 없이)

차량 앱의 시연 모드가 가상의 구급차를 서버로 보내고, 같은 차량 앱이 그 구급차를 받아 알립니다.

1. **에뮬레이터와 Virtual Console 켜기**
   ```
   adb forward tcp:8088 tcp:8088
   ```
   브라우저에서 http://127.0.0.1:8088/ 을 엽니다. 화면 아래가 OFFLINE이면 위 명령을 다시 실행하고 새로고침합니다.
2. **차량 앱 설치**: `gilteojwo-car_R번호.apk`를 에뮬레이터 창에 끌어다 놓거나 아래처럼 설치합니다.
   ```
   adb install -r -d gilteojwo-car_R번호.apk
   ```
3. **실행**: 앱 목록에서 **길터줘**를 열고 권한을 모두 허용합니다. 알림창에 "길터줘 수신 중"이 뜨면 준비가 끝난 것입니다. 이제 길터줘 화면을 닫아도 알림은 계속됩니다.
4. **내비 위 가장자리 빛 허용** ('다른 앱 위에 표시' 권한)
   ```
   adb shell appops set --user 10 com.gilteojwo.car SYSTEM_ALERT_WINDOW allow
   ```
5. **시연 시작**: 길터줘 화면 → **설정** → **송신 모드 켜기 (등록 코드 입력)** → 등록 코드 입력 → **확인** → **시연: 후방 접근 (90초)** 또는 **시연: 교차로 측면 접근**
   - 송신에는 등록된 긴급차량의 등록 코드가 필요합니다. **심사용 등록 코드는 접수 메일로 따로 보내 드립니다.**
   - 시연 구급차는 지금 내 차 위치를 향해 출발합니다.
6. **알림 보기**: 앱 목록에서 **내비게이션**을 열어 앞에 띄워 두면, 순서대로 이렇게 됩니다.
   - 관심: 상단 카드, 주황 조명, 알림음
   - 경고: 오는 쪽 가장자리 빛, 빨강 조명, 음성 "뒤에서 구급차, 약 500미터", 음악 소리 줄이기
   - 양보: 빨강 조명 깜빡임, 음성 "우측으로 비켜주세요"
   - 해제: "지나갔습니다"
7. **양보 확인 (길 열림)**: 양보 단계에서 Virtual Console로 **우측 방향지시등(Blink right)**을 켜거나 **기어 D + 브레이크**를 밟습니다.
   - 안내가 "확인했습니다"로 바뀝니다.
   - 송신 화면에 "알림 1대 · 양보 1대"가 뜹니다.
   - 길터줘 화면 → **양보 리포트**에 기록이 남습니다.
8. **주행 중 화면**: Virtual Console에서 기어를 **D**로 바꾸면 길터줘 화면이 그림 하나와 문구 한 줄로 단순해집니다. 교차로 장면은 브레이크를 밟고 서 있는 상태에서 "시연: 교차로 측면 접근"을 재생합니다.

> Virtual Console 창이 다른 창 뒤에 숨어 있으면 BRAKE 페달 값이 차로 가지 않습니다. 그럴 때는 Emulation Controls의 **Brake Pedal** 칸으로 바꿉니다.

## 폰 앱으로 실제 위치 보내기 (선택)

1. 폰에 `gilteojwo-phone_R번호.apk`를 설치하고 **길터줘 송신**을 엽니다. 위치 권한은 '항상 허용'으로 줍니다.
2. 등록 코드를 입력한 뒤 **긴급출동 시작**을 누릅니다. 폰 GPS 위치가 1초마다 서버로 갑니다.
3. **긴급출동 끄기**를 누르면 서버에서 위치가 바로 지워집니다.

## 필요한 설정

| 항목 | 내용 |
| --- | --- |
| 권한 | 위치(Pleos FusedLocation), 차량 속도, 알림은 첫 실행 때 허용합니다. 브레이크·방향지시등·조명 권한은 선언만으로 동작합니다. |
| 다른 앱 위에 표시 | 내비 위 가장자리 빛에 필요합니다 (위 4번). |
| 서버 | Supabase. 앱에는 공개 키(publishable)만 들어 있습니다. 표마다 접근 규칙(RLS)이 걸려 있어 공개 키로는 긴급차량 현재 위치 읽기와 익명 양보 확인 쓰기만 됩니다. 위치 송신은 등록 코드가 맞을 때만 서버 기능이 받아 줍니다. |
| 등록 코드 | 송신(시연 모드 포함)에만 필요합니다. 수신·알림은 코드 없이 동작합니다. |

## 사용한 Pleos SDK와 차량 기능

| 기능 | 사용 | 길터줘에서 하는 일 |
| --- | --- | --- |
| FusedLocation SDK 1.1.3 | `registerFusedLocationCallback` | 내 차 위치 (안 되면 안드로이드 기본 위치) |
| Vehicle SDK 2.3.2 · Brake | `registerBrakePedalStatus` | 정차·양보 판단 |
| Vehicle SDK 2.3.2 · TurnSignal | `registerTurnSignalState` | 우측 방향지시등으로 양보 감지 |
| Vehicle SDK 2.3.2 · Light | `setAmbientLightBrightnessColor` 등 | 단계별 앰비언트 조명, 끝나면 원래대로 |
| TextToSpeech SDK 3.3.1 | ON_DEVICE 모드 | 한국어 음성 안내 |
| 안드로이드 차량 표준 | `PERF_VEHICLE_SPEED`, `GEAR_SELECTION`, `CarUxRestrictions` | 속도·기어, 주행 중 화면 단순화 |

앱 목록의 **길터줘 시험**은 개발 초기에 위 SDK가 에뮬레이터에서 동작하는지 확인한 점검 화면입니다. 결과는 [docs/시험결과.md](docs/시험결과.md)에 있습니다.

## 프로젝트 구조

한 프로젝트에서 APK 두 개를 만듭니다 (product flavor).

| 폴더 | 내용 |
| --- | --- |
| `app/src/main` | 두 앱 공용: 거리·방향·접근 판정, 알림 단계·양보 문구 계산, 송신 화면·송신 서비스 |
| `app/src/car` | 차량 앱: Pleos 위치·차량 상태 읽기, 수신 서비스, 알림(카드·가장자리 빛·소리·음성·조명), 화면, SDK 점검 화면 |
| `app/src/phone` | 폰 앱: 폰 GPS로 송신 |
| `app/src/test` | 계산 자동 시험 129개 |
| `tools` | 개발용 가짜 구급차 스크립트 |

- 모듈별 설명: [docs/설명노트.md](docs/설명노트.md)
- 기능 사양: [docs/사양서.md](docs/사양서.md)

## 직접 빌드하기

- JDK 17, Android SDK (compileSdk 34)
- Pleos SDK는 `settings.gradle.kts`에 적힌 Pleos Maven 저장소에서 받습니다.

```
./gradlew assembleCarDebug assemblePhoneDebug
./gradlew testCarDebugUnitTest
```

main에 올리면 GitHub Actions가 시험을 돌리고 APK를 만들어 Releases에 올립니다.
